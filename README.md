## Materials
- Filament (I used PLA) and a 3D printer. I have the Bambu lab A1.
- Screw kits. I mostly used self-tapping 6 mm M3 screws, but some places needed longer screws. Also in the fingers I used standard screws, aswell as for attaching the fishing line to the motors. So I got 2 kits - one is self-tapping and one isnt:
  - [Self-tapping](https://www.amazon.co.uk/dp/B09NDPGJG1?ref=ppx_yo2ov_dt_b_fed_asin_title&th=1)
  - [Standard](https://www.amazon.co.uk/dp/B0DKXJTTPV?ref=ppx_yo2ov_dt_b_fed_asin_title)
- Rubber bands. I bought [these ones on AliExpress.](https://www.aliexpress.com/item/1005007403732170.html?spm=a2g0o.tm1000068802.d0.d0.69956f3dJwbY3e&pvid=4e509b79-8a66-4273-919e-0a03b35d26cb&pdp_ext_f=%7B%22ship_from%22%3A%22CN%22%2C%22sku_id%22%3A%2212000040598539465%22%7D&scm=1007.25281.487460.0&scm-url=1007.25281.487460.0&scm_id=1007.25281.487460.0&pdp_npi=6%40dis%21GBP%21%EF%BF%A17.34%21%EF%BF%A12.23%21%21%2163.74%2119.33%21%4021038c6f17898403940378452e0e8c%2112000040598539465%21gdf%21UK%218316613677%21X%211%210%21n_tag%3A-29911%3Bd%3A85a91e1e%3Bm03_new_user%3A-29895%3BpisId%3A5000000217423326&mainPicRatio=1&aecmd=true) They need a ~1cm diameter.
- SG90 Motors.
- Fishing line. [I bought this one.](https://www.amazon.co.uk/dp/B0CRHJZP28?ref=ppx_yo2ov_dt_b_fed_asin_title&th=1)
- Arduino starter kit. I used an Arduino mega one because it was all I could get at the time, but I'd recommend a smaller one.
- Batteries and battery holder with wires for breadboard. [I bought this one.](https://www.amazon.co.uk/dp/B07DJ4S46F?ref=ppx_yo2ov_dt_b_fed_asin_title)
